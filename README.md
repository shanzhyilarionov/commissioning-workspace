# Commissioning Workspace
Commissioning Workspace is a cross-platform desktop application for managing industrial commissioning workflows, from systemization and field verification to readiness assessment and final handover. It provides tools for organizing projects, tracking assets, managing checklists and tests, maintaining audit records, and generating reports. The application supports offline operation, allowing commissioning activities to continue without an internet connection.

## Requirements
- Node.js
- Rust toolchain
- Tauri prerequisites for your operating system

## Usage
- Install dependencies: `npm install`
- Run the application in development mode: `npm run tauri dev`
- Build the desktop application: `npm run tauri build`
